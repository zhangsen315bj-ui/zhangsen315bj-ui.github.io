Privacy Policy

Last updated: 14 November 2026

youtube-publisher is used only by its owner to publish to the owner's own YouTube channels.

Data accessed

With the owner's consent, the tool uses Google OAuth with the scopes youtube.upload and youtube to upload videos and read the status of those uploads on the owner's channels.

How data is used and stored

  • OAuth tokens are stored only on the owner's own computer and are used only to call the YouTube Data API on the owner's behalf.
  • Upload logs (video ID, title, time, status) are kept locally on the owner's computer as a record of what was published.
  • No data is sold, shared with third parties, used for advertising, or used to train models.

Google API Services User Data Policy

youtube-publisher's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Locally stored tokens are then deleted.
